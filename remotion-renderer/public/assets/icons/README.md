# Icons

Hand-written for Vimmer, released under CC0 1.0 (public domain dedication). Each is a 24x24
`viewBox` with plain black shapes; icon layers draw them as a silhouette in the layer's `color`,
so the original colors do not matter. Add your own SVGs anywhere under `public/` (keep a
`viewBox` so they scale cleanly).

| file | shape |
|------|-------|
| `star.svg` | five-pointed star |
| `check-circle.svg` | check mark cut out of a filled circle |
| `arrow-right.svg` | stroked arrow pointing right |
