# Brand fonts

`FiraSans-Thin.ttf` is Fira Sans Thin 4.106 (Mozilla Foundation and Telefonica S.A.), copied
unmodified from `/Library/Fonts` on the development machine. Its embedded license (OpenType `name`
table, IDs 13/14) reads "Licensed under the Open Font License, version 1.1 or later"
(http://scripts.sil.org/OFL); the license text is in `OFL.txt` next to it.

It is used by the brand-kit demo (`fixtures/brand.example.json`), registered under the family name
`Vimmer Demo Thin` so that a render can never pick up an installed "Fira Sans" instead of the file.
